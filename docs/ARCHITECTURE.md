# 🏗️ سیم‌کشی نسخه وب‌سایت — ابزار یدکی (abzaryadaki.com)

> مطابق قانون ۶ و ۸: سیم‌کشی قسمت‌های مختلف همیشه مستند می‌ماند؛ لایه‌بندی اصولی است.
> این سند مالکیت نسخه **وب‌سایت** است. نسخه موبایل پروژه مستقل آینده است و اینجا نمی‌آید (قانون ۱).

---

## ۱. لایه‌ها (Layering)

```
┌─────────────────────────────────────────────────────┐
│ L1  ورودی برنامه        src/app/layout.tsx / page.tsx │  فقط فونت، متا، رندر SiteApp
├─────────────────────────────────────────────────────┤
│ L2  طراحی              src/app/globals.css           │  توکن‌های رنگ/تایپ از فایل HTML مدیر
├─────────────────────────────────────────────────────┤
│ L3  وضعیت و مسیریابی   src/lib/shop-state.ts         │  ۵ استور zustand + روتر hash
├─────────────────────────────────────────────────────┤
│ L4  داده نمایشی        src/data/store.ts             │  محصولات/سفارش‌ها/کوپن/... فارسی
├─────────────────────────────────────────────────────┤
│ L5  قالب مشترک         src/components/site/chrome.tsx│  هدر/فوتر/جستجو/نوار اعلان
│                        cart-drawer.tsx / mobile-bar │
├─────────────────────────────────────────────────────┤
│ L6  صفحات مشتری        src/components/site/views/    │  ۱۸ نمای hash
├─────────────────────────────────────────────────────┤
│ L7  پنل ادمین          src/components/site/admin/    │  ورود + ۱۰ تب
└─────────────────────────────────────────────────────┘
```

قاعده: هر لایه فقط به لایه پایین‌تر وابسته است؛ صفحات (L6/L7) هرگز مستقیم به هم وصل نمی‌شوند و همه از L3 مسیریابی می‌گیرند.

## ۲. روتر Hash (همسان با فایل طراحی مدیر)

`src/lib/shop-state.ts` → `useRoute` + `setFromHash`:

| hash | صفحه | فایل |
|------|------|------|
| `#home` | خانه | `views/home.tsx` |
| `#shop` (+`?cat`/`?q`) | فروشگاه | `views/shop.tsx` |
| `#p-{id}` | جزئیات محصول | `views/product.tsx` |
| `#cats` | دسته‌بندی‌ها | `views/cats.tsx` |
| `#offers` | تخفیف‌ها و پیشنهادها | `views/offers.tsx` |
| `#about` | درباره ما | `views/about.tsx` |
| `#contact` | تماس با ما | `views/contact.tsx` |
| `#checkout` / `#done` | تسویه‌حساب / تکمیل سفارش | `views/checkout.tsx` |
| `#auth` | ورود/ثبت‌نام (کد یکبارمصرف پیامکی) | `views/auth.tsx` |
| `#account` | حساب من (سفارش‌ها/آدرس‌ها/اطلاعات) | `views/account.tsx` |
| `#track` | پیگیری سفارش (کد سفارش + موبایل) | `views/track.tsx` |
| `#wishlist` | علاقه‌مندی‌ها | `views/wishlist.tsx` |
| `#faq` | سوالات متداول | `views/static.tsx` |
| `#terms` | قوانین و مقررات + حریم خصوصی | `views/static.tsx` |
| `#returns` | رویه بازگرداندن کالا | `views/static.tsx` |
| hash ناشناخته | صفحه ۴۰۴ | `views/notfound.tsx` |
| `#admin` | پنل مدیریت (با گیت ورود) | `admin/admin-app.tsx` |

نقطه اتصال یکتا: `site-app.tsx` فقط بر اساس `page` رندر می‌کند.

## ۳. استورها (Zustand + persist)

| استور | کلید ذخیره | محتوا |
|-------|-----------|-------|
| `useRoute` | — (حافظه) | صفحه فعلی، pid، دسته، جستجو، مرتب‌سازی |
| `useCart` | `abzar-cart` (localStorage) | سبد خرید |
| `useData` | `abzar-data` | محصولات/سفارش‌ها/کوپن‌ها/نظرات/پیام‌ها/بنرها/آدرس‌ها/کاربران/تنظیمات (قابل ویرایش از ادمین) |
| `useAuth` | `abzar-user` | کاربر لاگین‌شده |
| `useWish` | `abzar-wish` | شناسه‌های علاقه‌مندی |
| `useAdmin` | `abzar-admin` (sessionStorage) | نشست ادمین (با گیت ورود) |
| `useUI` | — | کشوی سبد، شیت، توست |
| `useRV` | — | آخرین بازدیدها (مثل طراحی) |

همه استورهای persist بعد از mount با `rehydrateAll()` آب می‌شوند (جلوگیری از ناهماهنگی SSR).

## ۴. قالب مشترک (chrome.tsx)

- **AnnBar**: نوار اعلان بالای سایت.
- **Header**: لوگو، جستجو، منو، آیکون قلب → `#wishlist`، حساب (کاربر؟ `#account` : `#auth`)، سبد → کشو، کلید حالت تاریب، «پیگیری سفارش».
- **Footer**: لینک‌های `#account`، `#track`، `#wishlist`، `#faq`، `#terms`، `#returns`.
- **CartDrawer / MobileBar / Toast**: کشوی سبد، نوار پایین موبایل، توست سراسری (`useUI.say`).

## ۵. پنل ادمین (admin-app.tsx)

گیت ورود (نام کاربری/رمز — نمایشی: `admin`/`admin123`) → پس از ورود ۱۰ تب:

| تب | امکان |
|----|-------|
| داشبورد | آمار کلی + آخرین سفارش‌ها |
| محصولات | جدول + افزودن/ویرایش/حذف |
| سفارش‌ها | جدول + جزئیات + تغییر وضعیت |
| مشتریان | جدول کاربران |
| نظرات | صف تأیید/رد/حذف |
| کوپن‌ها | افزودن/فعال-غیرفعال/حذف |
| بنرها | فعال-غیرفعال/افزودن/حذف |
| پیام‌ها | صندوق تماس با ما (خوانده‌شده/حذف) |
| گزارش‌ها | گزارش فروش |
| تنظیمات | تنظیمات فروشگاه |

## ۶. سیستم طراحی (بدون تغییر گرافیکی — مصوبه ۵)

- پالت: کرم `#faf8f3` / جوهری `#1b1815` / کهربایی `#d97706` + حالت تاریب `.dark`
- فونت: وزیرمتن متغیر (`public/fonts/Vazirmatn-Variable.woff2`)
- اعداد و قیمت: فارسی/تومان (`src/lib/format.ts` → `F`، `fa`، `dg`)
- کلاس‌های همان طراحی: `w`، `panel`، `btn`، `grid`، `fm`، `crumb`، `adm-table` و...

## ۷. چرخه سفارش (سیم‌کشی کامل)

`#shop`/`#p-{id}` → افزودن به سبد (`useCart`) → کشوی سبد → `#checkout` (آدرس/ارسال/پرداخت/کوپن) → ثبت سفارش (`useData.addOrder` + کد سفارش) → `#done` → پیگیری از `#track` (کد سفارش + موبایل) → تغییر وضعیت از ادمین (تب سفارش‌ها) → مشاهده در `#account` سفارش‌های من.
