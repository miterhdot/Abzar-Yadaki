## [بررسی میزبانی Netlify] — ۱۴۰۵/۰۸/۱۰ — بدون تغییر کد (دستور ۱۶)

**دستور مدیر:** «https://www.netlify.com/ روی این هاست بیاریم بالا؟» (دستور ۱۶ در `docs/COMMANDS.md`)

**بررسی انجام شد:**
- سازگاری پروژه با Netlify راستی‌آزمایی شد: **بدون دیتابیس** (`src/lib/db.ts` هیچ‌جا import نشده — Prisma فقط وابسته نصب‌شده)، همه داده‌ها استاتیک/سمت کلاینت (Zustand persist)، دو مسیر سرور `/api` و `/api/ai-chat` روی Netlify به‌صورت Function اجرا می‌شوند، `public/` فقط ۱۲۸KB
- **آزمون محلی:** ساخت با حذف موقت `output:"standalone"` موفق بود (۴ مسیر: `/`، `/_not-found`، `/api`، `/api/ai-chat`) — پیکربندی بلافاصله عیناً بازگردانی شد و هیچ تغییری کامیت نشد
- مکانیزم احرازهویت SDK دستیار AI بررسی شد: `ZAI.create()` فقط از فایل `.z-ai-config` (پروژه/خانه/`/etc`) می‌خواند و آرگومان نمی‌پذیرد → روی Netlify یا باید `route.ts` حداقلی برای خواندن متغیر محیطی اصلاح شود (کلید فقط در پنل Netlify، هرگز در مخزن — مصوبه ۱۰) یا دستیار موقتاً پیام جایگزین خودِ طراحی را نشان می‌دهد (رفتار graceful از قبل ساخته شده)
- نتیجه: **انتشار ممکن است** با سه تنظیم فنی (صفر اثر گرافیکی): `netlify.toml` جدید + شرطی‌کردن `output:"standalone"` + تعیین تکلیف کلید AI — هر سه نیازمند تأیید و ورودی مدیر (حساب/توکن Netlify، تصمیم دامنه، کلید AI)

**وضعیت:** 🔲 **پیگیری همان روز:** مدیر هنگام ورود/ثبت‌نام Netlify با خطای «Your account has been suspended» (تعلیق حساب در مرحله احرازهویت) مواجه شد. محتمل‌ترین دلیل (غیرقطعی — فقط پشتیبانی Netlify دلیل قطعی را می‌دهد): محدودیت تحریمی سرویس‌های آمریکایی برای کاربران ایران. **گزینه‌های جایگزین ارائه شد:** ۱) میزبانی ایرانی (Liara/Chabokan/ArvanCloud/... — اجرای Node با خروجی standaloneِ موجود؛ بدون ریسک تعلیق؛ تأخیر کمتر برای مشتریان ایرانی؛ پرداخت ریالی) ۲) GitHub Pages (رایگان — همان حساب گیت‌هابِ فعالِ موجود؛ فقط استاتیک: دستیار AI پیام جایگزین می‌گیرد یا باید راه سرور جدا پیدا کند) ۳) سایر میزبان‌های خارجی (Vercel/Cloudflare — همان ریسک تحریمی Netlify؛ توصیه نمی‌شود). منتظر انتخاب مدیر — هیچ تغییری در کد انجام نشد
