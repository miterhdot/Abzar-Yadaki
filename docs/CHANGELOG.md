## [W5 — گام ۱: بازبینی بصری کامل] — ۱۴۰۵/۰۸/۱۰ — بدون تغییر کد

**دستور مدیر:** تأیید شروع فاز W5 («شروع») — گام ۱: بازبینی بصری همه صفحات در مرورگر (دسکتاپ + موبایل) و ارائه گزارش تصویری

**انجام شد:**
- اجرای سایت (`bun run dev`) و بازبینی خودکار با مرورگر: **۶۲ اسکرین‌شات فول‌پیج** (۳۴ دسکتاپ ۱۹۲۰px + ۲۸ موبایل ۳۹۰px) از هر ۱۸ نمای مشتری + گیت و ۱۰ تب ادمین + شیت سبد + جزئیات سفارش ادمین — ذخیره در `download/w5-review/` (فقط برای مدیر؛ به مخزن تعلق نمی‌گیرد)
- جریان‌های واقعی آزمون شد: افزودن به سبد (کشو مثل طراحی باز می‌شود) → تسویه با کوپن `WELCOME` (۱۰٪ اعمال شد) → ثبت سفارش (`#done`، کد `AY-DVRIW6`) → پیگیری با سفارش نمایشی `AY-K3M9X2` ✅ → ورود پیامکی ۳ مرحله‌ای (کد نمایشی) ✅ → حساب منِ لاگین‌شده ✅
- راستی‌آزمایی DOM/CSS: صفر خطای کنسول و صفر خطای صفحه؛ عرض سند همه ۱۶ نمای مشتری در موبایل دقیقاً ۳۹۰px (صفر سرریز افقی)؛ CSS کشوی سبد بایت‌به‌بایت مطابق فایل طراحی؛ `body{padding-bottom:128px}` مطابق طراحی (نوار پایین موبایل محتوا را نمی‌پوشاند)؛ رفتار شیت سبد (باز شدن پس از افزودن، باز ماندن در ناوبری) دقیقاً مطابق توابع `add()`/`go()` فایل طراحی مرجع
- **ایرادهای یافت‌شده (منتظر تأیید مدیر برای رفع):** ۱) تب «کد تخفیف» ادمین در موبایل: جدول ۴۸۷px داخل پنل ۳۵۰px با `overflow:visible` → عرض سند ۵۱۶px و اسکرول افقی کل صفحه؛ ۲) داشبورد ادمین در موبایل: سرریز جزئی ۴px (عرض سند ۳۹۴px) — هر دو فقط در پنل ادمین موبایل، بدون هیچ تأثیر گرافیکی/محتوایی
- نوار باریک کناری در برخی اسکرین‌شات‌های فول‌پیج = سایه کشوی بسته (مطابق طراحی) + artifact کپچر؛ رندر زنده تمیز است (با نمونه‌برداری پیکسلی و DOM راستی‌آزمایی شد)
- ابزار بازبینی: `scripts/w5-shots.sh` و `scripts/w5-sheets.py` (قابل اجرای مجدد)

**راستی‌آزمایی:** هیچ فایلی از `src/` تغییر نکرد (کد فریز)؛ فقط این سند + دو اسکریپت ابزار اضافه شد.
